# Module Configuration

## Example

There is only one required field in configuration - `storage`.

```typescript title="app.module.ts"
RateLimiterModule.forRoot({
    scope: "my-scope",

    // storage configuration (Map or Redis)
    storage: {
        type: "in-memory",
        gcTime: 15 * 60 * 1000 // time to clear `dead` data from memory
        gcBatchSize: 1000 // batch size for `dead` data collection
    },

    // strategy configuration
    strategy: "token-bucket",
    strategyOptions: {
        fixedWindow: {/* */},
        tokenBucket: {/* */},
        slidingWindowCounter: {/* */},
        slidingWindowLog: {/* */},
        leakyBucket: {/* */}
    },

    // default providers
    defaultProviders: {
        keyExtractor: MyCustomKeyExtractor,
        errorFactory: MyCustomErrorFactory,
        optionsFactory: MyCustomOptionsFactory
    }
});
```

## Properties description

|Property|Type|Description|
|:-|:-|:-|
|`scope`|`string`|Defines scope for data record key|
|`storage`|`object`|Defines storage options|
|`strategy`|`Strategies`|Defines default rate limiting algorithm|
|`strategyOptions`|`object`|Defines default options for rate limiting algorithms|
|`defaultProviders`|`object`|Defines providers that will be used by default|

### Storage

Properties of this object defines storage options.

|Property|Storage Type|Description|
|:-|:-|:-|
|`type`||Defines storage type|
|`gcTime`|`in-memory`|Defines the dead data records collection interval|
|`gcBatchSize`|`in-memory`|Defines the data records collection batch size |
|`adapter`|`redis`|Provider object/provider that will be used to `Redis` access|
|`failingStrategy`|`string`|Defines how to handle `Redis` failure|

### Strategy options

Properties of this object sets default options for all rate limiting algorithms.

|Algorithm|Property|Description|
|:-|:-|:-|
|`fixed-window`|`limit`|Defines requests count in window|
||`ttl`|Defines window length in milliseconds|
|`token-bucket`|`capacity`|Defines the volume of bucket|
||`refillRate`|Defines how much tokens refills in 1 millisecond|
||`ttl`|Defines data records ttl|
|`sliding-window-counter`|`limit`|Defines requests count in window|
||`windowMs`|Defines window length in milliseconds|
|`sliding-window-log`|`limit`|Defines requests count in window|
||`windowMs`|Defines window length in milliseconds|
|`leaky-bucket`|`capacity`|Defines the volume of bucket|
||`leakRate`|Defines how much tokens leaks in 1 millisecond|
||`ttl`|Defines data records ttl|

### Default providers

Properties of this object defines providers that will be used by default.

|Provider|Description|
|:-|:-|
|`keyExtractor`|Defines key extractor provider that will be used by default|
|`errorFactory`|Defines error factory provider that will be used by default|
|`optionsFactory`|Defines options factory provider that will be used by default|
