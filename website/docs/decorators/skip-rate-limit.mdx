# SkipRateLimit

You can also skip rate limiting for method/controller:

```typescript
import { RateLimitGuard, SkipRateLimit } from "nestjs-multi-limiter";

@Controller()
@UseGuards(RateLimitGuard)
export class MyController {
    // Rate limiting for this method will be enabled
    public method1() {}

    // Rate limiting for this method will be skipped
    @SkipRateLimit()
    public method2() {}
}
```

:::info[Remember]
If both `@RateLimit` and `@SkipRateLimit` decorators are applied to same method/controller, `@SkipRateLimit` decorator has a **higher priority** than `@RateLimit` decorator. 
:::
