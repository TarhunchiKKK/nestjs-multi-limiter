# Via Object

Let's create object that will be used as `Redis` adapter.

### Setup your adapter object

Let's create object that use `Redis` instance from `ioredis` package.

```typescript title="redis.adapter.ts"
import Redis, { type RedisValue } from "ioredis";
import type { IRedisAdapter } from "nestjs-multi-limiter";

// 📌 TRICK: This client already can be used as adapter
export const RedisClient = new Redis(/* ... */);

export const MyRedisAdapter: IRedisAdapter = {
    eval: async (script, numKeys, ...args) => {
        return await RedisClient.eval(script, numKeys, ...args);
    }
} 
```

### Inject your Redis provider

Now we can use our object as `Redis` adapter.

```typescript
RateLimiterModule.forRoot({
    storage: {
        type: "redis",
        adapter: MyRedisAdapter // or use `RedisClient` directly
    }
});
```
