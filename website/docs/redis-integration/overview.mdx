# Overview

For using Redis storage you need to provide object or provider that implements `IRedisAdapter` type. This object/provider will be used for Redis access.

:::info[Trick]
`Redis` instance from `ioredis` package already implements `IRedisAdapter` type.

You can use it as adapter.
:::

:::warning[Important]
Built‑in strategies expect to receive 0 or 1 as the return value of the Lua script. **Be careful with influencing the return value**.
:::
