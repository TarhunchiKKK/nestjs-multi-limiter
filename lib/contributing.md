# Contributing to This Library

Thank you for your interest in improving this project! We value your feedback, bug reports, and feature ideas. 

Please note that this is a closed-contribution project. We do not accept Pull Request (PR) contributions from external developers. However, we highly encourage you to help us improve the library by reporting issues and suggesting new features.

---

## 🐛 Reporting Bugs

If you find a bug, please use our GitHub Issues page to report it. Before opening an issue:

1. Check existing issues: Search the open issues to ensure your bug hasn't already been reported.
2. Update the library: Make sure you are using the latest version of the library.
3. Use the template: When creating a new issue, select the Bug Report template and fill out all required fields.

> Important: Always provide a Minimal Reproducible Example. It is impossible for us to debug your project without seeing an isolated code snippet that reproduces the error.

---

## 🚀 Suggesting Features

We welcome ideas for new functionality or API improvements. To submit a feature request:

1. Look through open and closed issues/discussions to see if someone else has already proposed the same idea.
2. Use the Feature Request template on the GitHub Issues page.
3. Clearly explain why you need this feature and provide an example of how you imagine the new API syntax.

---

## 🛑 Pull Requests (Code Changes)

We do not accept external Pull Requests for code changes, documentation fixes, or formatting updates. 

* Any unsolicited Pull Requests will be closed without review.
* If you find a security vulnerability, please do not open a public PR or issue. Instead, report it privately via GitHub Security Advisories or contact the maintainer directly.

Thank you for understanding and helping us keep the library stable!
